# Invoice Pro

A lightweight client-side invoice management starter app.

## Structure

- `index.html` – app shell and entry point.
- `css/style.css` – layout and presentation.
- `js/classes` – invoice model classes.
- `js/services` – storage and API helpers.
- `js/utils` – shared helpers and validation.
- `js/ui` – UI rendering and interaction.
- `js/main.js` – app initialization.

## Getting Started

Open `index.html` in your browser to launch the app.
